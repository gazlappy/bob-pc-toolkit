How this app behaves

  • Startup items are disabled, not deleted — the same reversible switch Task Manager uses. Turn one back on any time.
  • Cleanup always scans and shows you sizes first. Nothing is removed until you tick it and press Clean.
  • Large files and duplicate copies are moved to the Recycle Bin, never deleted outright — and a duplicate group can never lose every copy.
  • Uninstalling runs the program's own uninstaller. When that will not run, Force remove quarantines the program rather than deleting it.
  • Files that are open or in use are skipped rather than forced.

Registry

What this does and does not touch

  • An entry is only listed when it names a real path that is definitely not there. No guessing at what looks unused.
  • Paths on unplugged drives and offline network shares are ignored, so a disconnected disk never looks like junk.
  • Everything removed is backed up first to a .reg file you can restore from the Backups tab.
  • Deliberately left alone: file associations, COM/CLSID registrations, and anything Windows Installer manages — that is where registry cleaners break machines.

How this works

            
    
              
  • Uninstalling runs the program's own uninstaller. Use it first — it knows what it installed.
    • 
              
  • If that uninstaller will not run, Force remove moves the folder, its shortcuts and its Add/Remove Programs entry into quarantine. Nothing is deleted until you discard it in Backups, and one Restore puts it all back.
    • 
              
  • Sizes come from what the installer recorded, which is often wrong or missing. Measure walks the folder for the real figure.
    • 
              
  • Rows tagged Files missing are leftovers — the program is gone but its entry remains. The Registry tab clears those.
